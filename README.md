# نومي — أساس التطوير 0.1

بداية تنفيذ مستقلة بتاريخ 4 أكتوبر 2026. الحزمة أساس تطوير وليست منتجًا جاهزًا للنشر.

## التشغيل

يتطلب Node.js 24. لا توجد حزم خارجية أو مفاتيح خدمات مطلوبة لتشغيل API.

```sh
npm run check
npm test
npm start
```

الخدمة محلية على `http://127.0.0.1:3000`. المسارات: `/health/live`، `/health/ready`، `/v1/meta`.
جاهزية الخدمة تعيد 503 عمدًا حتى يُنفذ اتصال قاعدة البيانات فعليًا.

لتشغيل قاعدة التطوير باستخدام Docker Compose:

```sh
cp .env.example .env
# ضع كلمة مرور محلية في .env
 docker compose up -d db
```

SQL الأولي يطبق عند إنشاء volume جديد فقط. لا تحذف volume لتحديث قاعدة قائمة؛ يلزم runner للهجرات في المرحلة التالية. حساب PostgreSQL الحالي حساب تهيئة محلي؛ لا يستخدم في الإنتاج أو لخدمة التطبيق.

## ما يحتويه المشروع

- API محلي مع فحوص الحياة والجاهزية ومعرّف لكل طلب.
- نموذج بيانات PostgreSQL للقصة ونسخها والادعاءات والأدلة وأصل النقل والتصحيحات والصوت والمهام.
- بوابة تحقق تحريرية قابلة للاختبار قبل إنشاء مسار النشر.
- اختبارات API وسياسة الإسناد وسير تحقق GitHub جاهز للرفع.
- دراسة المرجع الأصلية في docs/lisa-study-and-saudi-product.md.

## حدود التنفيذ

لا اتصال PostgreSQL داخل API بعد، ولا تسجيل دخول أو واجهة أو جلب مصادر أو توليد نصوص/صوت. لا عامل مهام يعمل بعد. سياسة التحقق البرمجية لا تثبت صحة الخبر؛ المحرر يتحقق من مضمون الدليل. SQL لا يمنع كل تعديل ضار أو كل نشر غير مسند؛ يجب بناء خدمة نشر بمعاملة وتفويض قبل أي نشر. المستودع المرجعي: https://github.com/sabq4org/nomi . لم تُنشأ موارد تشغيل سحابية. لا أخبار تجريبية توهم بأنها حقيقية.
